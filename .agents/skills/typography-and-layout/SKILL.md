# typography-and-layout

Cargar únicamente cuando la tarea lo requiera; no activa un agente adicional.

1. Leer especificación aprobada y revisar solo componentes asignados y tokens actuales.
2. Definir escala, medida de línea, interlineado, contraste, retícula, espacios y puntos focales con contenido real; verificar fuentes, licencia y glifos/idiomas.
3. Proponer cambios en tokens existentes; no sustituir globals.css ni importar paletas del framework automáticamente.
4. Revisar títulos largos, zoom 200 %, orden de lectura y anchos críticos. Evitar texto esencial como imagen o una fragmentación que degrade lectores de pantalla.
5. Capturar estados comparables y entregar criterios/restricciones; visual-audit revisa sin editar.
