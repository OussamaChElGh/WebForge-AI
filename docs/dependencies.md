React/ReactDOM son peers ^19; GSAP ^3.15 y Motion ^14.7 son peers opcionales por componente. No se afirma compatibilidad ejecutada con React 18 ni versiones anteriores: no actualizar clientes automáticamente para instalar el framework. Las devDependencies son del laboratorio maestro; no convertirlas todas en runtime del cliente.

No se añade Next.js porque no hay aplicación Next a construir; los componentes marcan límites cliente y SSR se prueba con React. El build específico de Next y su versión/router deben verificarse en la adopción. No se añaden Three/Fiber, Lenis, Convex, auth ni componentes de catálogos para un efecto no aprobado.

La licencia propia no estaba definida en el repositorio: package.json permanece private y se marca UNLICENSED para no atribuir una licencia pública inventada. La reutilización interna por el propietario no es una publicación npm. Antes de distribuir, resolver licencia propia y conservar licencias de dependencias/assets. Motion Primitives no se incorpora hasta verificar el texto de licencia del artefacto; React Bits no se redistribuye como catálogo. Ver references.md.
