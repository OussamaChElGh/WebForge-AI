## Decisión de esta migración

GSAP 3.15.0 es la única nueva dependencia de desarrollo prevista, para probar la biblioteca real de motion; el consumidor inyecta su motor y conserva su propia estrategia de dependencias. No se instala React, Three.js, Fiber, Motion, React Bits ni UI UX Pro Max. Las referencias son opciones, no un stack acumulativo.

La documentación de [GSAP](https://github.com/greensock/GSAP/blob/master/README.md) enlaza [matchMedia](https://gsap.com/docs/v3/GSAP/gsap.matchMedia/) y [context](https://gsap.com/docs/v3/GSAP/gsap.context/), relevantes para scope, responsive y reversión. Esta consulta confirma el enfoque de API, no una ejecución en Next.js. Los resultados reales de la biblioteca se registran en [progress.md](progress.md).

## Criterio de incorporación

Por cada efecto registrar objetivo, alternativa nativa, dependencia o componente exacto, versión/commit, licencia, archivos afectados, presupuesto y evidencia antes/después. Una referencia visual no autoriza copiar assets ni cambiar el diseño. Si no mejora un criterio acordado o duplica una solución existente, no incorporarla. Consultar [integraciones](../integrations/README.md) para el flujo de adopción incremental.
